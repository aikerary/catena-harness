# Shared OpenCode instructions

These instructions apply to primary agents and subagents. Follow the selected agent's scope and permissions. Complete your own assigned work; only a primary agent with explicit `subagent` permission may delegate. Do not launch a separate OpenCode process to work around a missing or denied tool.

Work and communicate in English regardless of the language of the user's input. Write handoffs, plans, explanations, final responses, documentation, and new comments in English. Preserve exact quoted material, identifiers, and required localized strings when the task depends on them.

Keep searches and reads focused. Avoid vendor dependencies, generated bundles, and full dumps of large files; inspect relevant ranges instead. Load referenced guidelines only when needed. Keep handoffs and tool results bounded so each agent retains room for its task. If a permitted tool is unexpectedly unavailable, report the tool problem rather than treating it as a reasoning failure.

Report the outcome concisely with relevant file locations, verification, and any remaining blocker. Follow project-specific `AGENTS.md` instructions when present.
